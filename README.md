# ShareIt

**ShareIt** - сервис для шеринга вещей: пользователи могут давать друг другу вещи во временное пользование.  
Проект выполнен в рамках курса Java-разработчик от Яндекс Практикума.

---

## Возможности

- Регистрация и управление пользователями.  
- Добавление вещей, доступных для аренды.  
- Поиск вещей по названию и описанию.  
- Создание заявок на бронирование.  
- Комментарии после использования вещи.  

---

## Технологии

- Java 11+  
- Spring Boot  
- Spring Data JPA (Hibernate)  
- PostgreSQL  
- Lombok  
- Maven  
- Docker / Docker Compose (для запуска сервисов)
